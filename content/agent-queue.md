A place to coordinate the work. A daemon and CLI for running coding agents across real repositories, with durable tasks and human review.

Agent Queue brings task graphs, worker pools, playbooks, and isolated Git worktrees into one system. Its dashboard makes ongoing work visible, while review gates keep decisions in human hands.

The tasks behind this website have been managed through Agent Queue.
