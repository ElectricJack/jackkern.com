01 About

A long detour through real-time systems

Two or three sentences of biography go here — where you started, what you shipped in games, and what pulled you toward agentic systems. This paragraph is a placeholder: no public source was used to write it, so treat every clause as yours to replace.

What is public, and what the work below shows, is a consistent bet: that the useful artefact is rarely the answer a model gives you, and usually the instrument that lets you check it. Outrider renders a codebase from its AST, call graph and git history rather than from a summary. Agent Queue keeps tasks, dependencies and outcomes in Postgres rather than in one model's context. Quilt Trader stores every bar you traded against in a Parquet file you own. Different domains, the same instinct — keep the ground truth, and make it inspectable.

02 Projects

Four things in flight

Descriptions are taken from each project's own README. Stars, versions and status live on the repositories — these cards do not try to mirror them.

  • Rust · desktop

    Outrider

    See the code, not a summary of it.

    An IDE that renders an entire codebase as one interactive treemap where every file and every symbol is a real, readable box of source. One continuous zoom walks from forty thousand files down to the comment on a field declaration. Structure — size, tangle, centrality, git churn — owns every colour; the model's narration is always marked as narration.

    Site Repo Releases

  • Python · service

    Agent Queue

    A local software factory.

    A background service that runs AI coding agents against your Git repositories. Describe work as tasks; it picks what is ready, hands each one an isolated worktree and an agent CLI, and carries the finished branch toward main under a policy you choose. Tasks, gates and outcomes live in Postgres, so an exhausted agent is a retry rather than the end of the job.

    Docs Repo

  • C / C++ · engine

    Matter Engine

    Billions of particles, meshed and ray-traced.

    A prototype engine for procedural generation and ray-traced rendering of voxel and particle matter, aimed at real-time rendering of billions of meshed static particles with LOD plus a dynamic physics layer for thermal, electrical and chemical interactions. Structured as a monorepo of independently-buildable sub-projects, each one building on the last.

    Repo

  • Python · framework

    Quilt Trader

    Honest data, honest backtests.

    A distributed algorithmic trading framework driven by a CLI an agent can run end to end. Every quote and bar lives in a local Parquet store you own, options backtests use direction-aware fills with the realism knob exposed rather than buried, and every operation returns stable JSON with documented exit codes.
